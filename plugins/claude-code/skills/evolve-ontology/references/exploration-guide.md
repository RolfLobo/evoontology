# Exploration Guide

Use this guide when evolution stagnates, similar patches repeat, or the current problem explanation is weak.

Broaden the search by:

- comparing successful, failed, improved, and regressed trajectories;
- examining analysis needs that were never attempted;
- testing representative or counterfactual cases;
- checking whether the Agent compensates for missing semantics through inefficient tool use;
- reconsidering whether the limitation belongs to Content, Tool, or Schema;
- generating alternative causal explanations before proposing another patch.

The goal is to discover a more informative mechanism, not merely a different implementation of the same unsupported idea.
