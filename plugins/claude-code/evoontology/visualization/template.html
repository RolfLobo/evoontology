欢迎使用 EvoOntology 本体层浏览器

探索面向 Data Agent 构建的 Agent-first 自进化本体层

这个页面是什么？

本页面是 EvoOntology 当前 ontology layer 的只读快照，不修改任何本体层状态。该层围绕 Agent 的工作负载构建，通过 Agent 的 MCP 工具接口按需访问，并根据 Agent 的执行轨迹持续进化。本页面将当前本体版本可视化为图谱：业务概念（Term）如何落地到数据库表列（Mapping）、受哪些使用约束（Constraint）、由哪些证据（Evidence）支撑，以及概念之间的语义关系（Relation）。

四个视图

结果与问题 — 从问题查看语义、证据、执行结果和进化效果

  • 本体内容— 交互式语义图谱，支持搜索、过滤、展开 / 收起
  • Schema 层— 对象类型、受控关系取值与结构引用规则
  • Tool 层— 智能体查询本体层时使用的 MCP 工具

版本与对比

  • 使用顶部版本选择器查看任一已嵌入版本；旁边的徽标会说明当前查看的是激活版本还是指定版本
  • 有至少两个版本时，点击“对比”，以当前版本为左侧并选择右侧版本；本体内容、Schema 层和 Tool 层均支持并排对比
  • 点击新增、删除或修改统计可查看具体差异；“突出差异”只控制视觉强调，不会改变所选版本

浏览与操作

  • 点击图中的节点、连线或 Schema / Tool 卡片，在右侧面板查看详情并定位对象
  • 顶栏可搜索任意对象；若出现警告徽标，点击可查看因引用无法解析而跳过的记录
  • 双击 Term 或使用“展开全部 / 收起全部”控制关联对象；显示过滤器可控制关系、引用及各类非核心节点
  • “适配视图”只缩放并居中当前可见内容；“恢复初始”会清空交互状态并恢复首次打开的布局
  • 拖动空白处可平移，滚轮可缩放；可在右上角或本指南中切换中文和英文
  • “不再自动显示”只关闭后续开屏；仍可通过顶部“?”或介绍条中的“使用指南”重新打开
